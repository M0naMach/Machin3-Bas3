# M0na Machin3 Website

The official website for M0na Machin3 - a platform for bespoke AI companions and digital relationships. This repository contains the frontend website built with Next.js, featuring:

- **Modern Design System**: Custom opalescent theme with terminal-inspired navigation
- **Command Navigation**: Unique command-line style interface for site exploration
- **Business Showcase**: Services, timeline, and collaboration opportunities
- **Future Integrations**: Prepared for Notion and Framer integrations

## Features

- Responsive design with custom Anurati font
- Interactive timeline and journey visualization
- Service portfolio with mosaic grid layouts
- Command navigation system with terminal aesthetics
- Opalescent visual effects and animations

## Tech Stack

- Next.js 14 with App Router
- Tailwind CSS with custom design system
- Radix UI components
- TypeScript
- Custom font integration (Anurati)
